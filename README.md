# Mini Sistema bancario

En este repositorio se encuentra uno de mis primeros proyectos de programacion, Esta desarrollado en JAVA con el fin de fortalecer la Programacion Orientada a Objetos.
Cada persona puede tener como maximo 5 cuentas con su nombre, estas cuentas podran hacer depositos, transacciones a otras cuentas y pagos de servicios. Tambien se podra ver un historial de transacciones por cuenta
